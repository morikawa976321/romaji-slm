# romaji-slm 体験版の使い方

1. この zip をどこかに解凍する（パスに `&` を含まない場所。例: `C:\romaji-slm-trial`）。
2. 解凍したフォルダの **`run.cmd`** をダブルクリックする。初回は準備に数分かかる。ブラウザが自動で開く。
3. ページでローマ字を打ち、ボタンで選ぶ。
   - **比べる**: 軸を選び、ローマ字を打って Enter（文を考えたくなければ「例文を入れる」）。出た A/B/C のうち「一番いい」を1つ、ダメなものに「致命的」を押す。どれでもよければ「全部問題ない」。
   - **打ってみる**: 普段どおりに打って Enter。結果が下の欄にたまっていく。気が向いたら「使えた」「直した」を押す。
   - **まとめ**: 「自動計測を実行」を押して終わるまで待つ（数分）。
4. **まとめ** の枠の「コピー」を押し、そのまま貼って返す。

- 選んだ結果はその場で保存されるので、途中でブラウザを閉じても消えない。続きは `run.cmd` をもう一度ダブルクリックする。
- 終わるときは黒いウィンドウを閉じる。
- 止まったときは、黒いウィンドウに出ている内容と `trial\out` フォルダを送ってほしい。
