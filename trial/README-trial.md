# romaji-slm 体験版の使い方

1. この zip をどこかに解凍する（パスに `&` を含まない場所。例: `C:\romaji-slm-trial`）。
2. 解凍したフォルダの **`run.cmd`** をダブルクリックする。ブラウザが自動で開く（初回は準備に数分かかる）。
3. 画面に出る順にボタンを押す（文字を打つ必要はない）。
4. 最後に **「結果をコピー」** を押し、そのまま貼って返す。

## 困ったとき

- `run.cmd` を開いたときに「Windows によって PC が保護されました」「発行元を確認できませんでした」と出たら、「詳細情報」→「実行」（zip をネットから持ってきたときに付く印のため）。
- ブラウザが開かないときは、黒いウィンドウに出ている `http://127.0.0.1:…/` を手でブラウザに貼って開く（`trial\out\url.txt` にも書いてある）。
- 途中でブラウザを閉じても、選んだ内容は保存されている。同じ黒いウィンドウが開いているうちにページを開き直せば続きから。
- 終わるときは黒いウィンドウを閉じる。
- 止まったときは、黒いウィンドウの最後の表示と `trial\out` フォルダをそのまま送ってもらえれば原因を調べられる。
