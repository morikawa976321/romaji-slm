romaji-slm 体験版

    はじめに

    ローマ字かな漢字変換を、画面の順にボタンを押して試します。文字を打つ必要はありません。

    1. 句読点: 例文 3 つの変換結果を見比べて、句読点の形を選ぶ
    2. 英字: 例文 3 つで、英字の大文字・小文字の整え方を選ぶ
    3. 体感: 選んだ設定で例文を変換してみる（自分の文も試せます）
    4. 結果: 自動で短い計測をして、結果をコピーする

    選んだ内容は押した時点で保存されます。途中でページを閉じても、もう一度開けば続きからです。

    準備中（モデルを読み込んでいます）…

    1. 句読点

    句読点を打たずに入力した例文です。「この例を変換」を押し、出てきた案のうち良いほうを選んでください。

    2. 英字の表記

    英字を含む例文です。「この例を変換」を押し、出てきた案のうち良いものを選んでください。

    3. 体感

    ここから先は任意です。自分の文を試すなら、ローマ字を打って Enter。

      4. 計測と結果

      短い計測をしています。そのままお待ちください（操作は要りません）。

      コピーしたら、そのまま貼って返してください。終わるときは黒いウィンドウを閉じます。
